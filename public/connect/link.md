# Link your phone browser

Open [/connect/link/](/connect/link/) on your phone. Ask an already connected Claude or Codex: “Link my phone to A1 Scout, code XXXX-XXXX”. Codes expire after 10 minutes and can only be collected once.

This browser receives a secure HttpOnly cookie; the device key is never shown. A returning Scout workspace browser links immediately. Linking does not upload chats. Next, choose an export and review names and counts locally before sending.
