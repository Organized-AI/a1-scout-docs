# Import phone chats

Bring Claude and ChatGPT chats into your Scout work profile. Only names and counts leave this device, after you review and send.

1. Link this browser at [/connect/link/](/connect/link/).
2. Claude: Settings → Privacy → Export data. ChatGPT: Settings → Data controls → Export data. Both email a download link. Save the download to Files. An export covers all chats on the account, not only phone ones.
3. Choose the .zip or conversations.json from Files. We read only conversations.json locally in a worker (100 MB archive, 64 MB chat JSON limit).
4. Review sessions, apps, tools, commands, languages, packages and models. Then choose Send to my work profile.

Titles, messages, file names, URLs and emails are never sent. No full chats are uploaded. Reimporting the same conversation updates its summary rather than adding a duplicate session. [Privacy](/privacy/).
