Privacy

How the A1 Scout connector for Claude and Codex handles your session history.

What it reads

Your Claude Code, Cowork and Codex session logs on your own computer, for the apps you leave switched on. You can leave out any project by folder name.

What it sends to Scout

  • For each session: start and end time, number of events, and an anonymous fingerprint of the project.
  • Counts of the tools, commands, languages, libraries, packages and Hugging Face model names used.
  • An anonymous ID for your computer.

What it never sends (unless you turn on full transcripts)

  • Your prompts, the assistant's replies, or file contents.
  • File paths, folder names, project or client names, web addresses or email addresses.
  • Passwords, API keys or tokens. Anything that looks like one stops the whole upload.

Scout checks every upload again on its side with the same rules and rejects it if anything slips through.

Full transcripts (opt-in, off by default)

If you turn on Full transcripts (a checkbox in the Claude extension's settings, or ask Claude or Codex to turn it on), Scout also stores each session's complete log: your prompts, the replies, code, file contents and file paths. The first sync after you turn it on sends your history; later syncs send sessions that changed.

  • Before anything leaves your computer, text shaped like an API key, access token or private key is replaced with [redacted:credential]. This catches common formats, not every secret, so leave out any project you don't want stored.
  • Transcripts are stored privately for your workspace only, and only for sessions whose summary you already sent.
  • Ask Claude or Codex to "delete my transcripts from Scout" at any time. Every stored transcript is deleted and the setting turns off; summaries are kept.

Who sees it

Only the workspace you approved in your browser. Scout uses it to rank models and tools for you. We don't sell it or share it.

Stopping

Ask Claude or Codex to "disconnect from A1 Scout", or remove the extension or plugin. To delete what Scout already has, email the address on your invite and we'll remove your workspace.

The connector is open source (MIT): github.com/Organized-AI/a1-scout-docs.
