# A1 Scout

A1 Scout finds open models, datasets, Spaces, papers and code on Hugging Face and GitHub that fit your work. Approve picks for storage you own, or ask about a hosted stash. Private beta: join the waitlist on the home page.

## Connect your AI work

- Claude Desktop: [download the extension](/download/a1-scout.mcpb), double-click, choose session sources, then ask “connect me to A1 Scout”.
- Codex: add the plugin marketplace `Organized-AI/a1-scout-docs`, Git ref `main`, sparse paths empty; install A1 Scout and ask to connect.
- Claude Code: `/plugin marketplace add Organized-AI/a1-scout-docs`, then `/plugin install a1-scout@organized-ai`.
- Phone chats: [import a Claude or ChatGPT account export](/connect/import/), [link the browser](/connect/link/), or follow the [remote connector setup](https://github.com/Organized-AI/a1-scout-docs/blob/main/connect/README.md#phone-chats-and-remote-mcp).

Local logs (including Claude Desktop / Cowork) and exports are summarized on your device. Preview tools, languages, packages and models with counts. Exports cover all account chats, not only phone chats. Optional live logging is model-reported, not guaranteed device-local or automatic. ChatGPT phone support is to verify. Computer full transcripts are a separate opt-in, off by default. [Privacy](/privacy/). [Docs](/docs/).
